# Hampus Lang — Portfolio

Personal portfolio of Hampus Lang, frontend developer in Tbilisi. Live at [hampuslang.com](https://www.hampuslang.com/).

## Stack

- **React 18** + **TypeScript**, built with **Vite**
- **Tailwind CSS** for layout utilities, with design tokens in `src/index.css`
- **GSAP** (ScrollTrigger, ScrollSmoother, SplitText) via `@gsap/react` for all motion

No WebGL: depth comes from CSS 3D transforms driven by GSAP, which keeps the bundle small and the screenshots sharp.

## Structure

```
src/
  data/          projects.ts, profile.ts — all copy and facts live here
  lib/gsap.ts    plugin registration + the motion system (eases, durations, media queries)
  components/    Preloader, Nav, Hero, Manifesto, Work, Story, Toolkit, Contact, RevealText, SmoothScroll
  pages/         Index (home), NotFound
public/assets/
  profilewebp.webp, projects/*.webp   original photographs and screenshots (never modified)
  optimized/                          resized derivatives generated by `npm run images`
```

## Motion & accessibility

- All animation is set up inside `gsap.matchMedia()` and reverted on unmount.
- `prefers-reduced-motion: reduce` disables the preloader, smooth scrolling, pinning and all reveals; every piece of content is in the HTML and readable without animation.
- The horizontal project sequence only runs on screens ≥ 1024px; smaller screens get a vertical sequence. Smooth scrolling only runs on desktop with a fine pointer.

## Development

```sh
npm install
npm run dev        # http://localhost:8080
npm run build      # production build to dist/
npm run preview    # serve the production build
npm run lint
npm run test       # content + render tests (Vitest)
npm run images     # regenerate responsive image derivatives from the originals
```

To add a project: drop the original screenshot in `public/assets/projects/`, run `npm run images`, and add an entry to `src/data/projects.ts`.

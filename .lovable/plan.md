

# Brutalist Designer Portfolio

A high-end brutalist portfolio website with raw editorial energy, aggressive typography, and intentional anti-corporate design.

## Design System
- **Palette**: Black, white, off-white (#F5F5F0), dark gray — with acid yellow (#CDFF00) as a sparse accent
- **Typography**: Inter + a bold condensed font (Space Grotesk or similar from Google Fonts), dramatic size contrasts (8rem headlines down to 0.75rem labels)
- **Visual language**: Hard borders, no border-radius, visible grid lines, barcode/index notation, uppercase labels, editorial dividers

## Sections

### 1. Hero
- Full-viewport, split asymmetric layout
- Name in massive stacked uppercase type (covering ~60% of viewport width)
- Rotating "stamp" element with role title spinning slowly
- Short designer statement in small monospace type
- "VIEW WORK ↓" CTA as a blocky bordered button
- Geometric shapes and harsh grid overlay lines as visual texture

### 2. About
- Two-column offset layout — text block pushed right, grayscale image placeholder pushed left with a raw border frame
- Confident, manifesto-style bio text with mixed type sizes
- Index numbers and archive-style labels ("001 — ABOUT")
- Editorial divider lines

### 3. Selected Work (4 projects)
- Alternating large brutalist project cards — each feels like a poster
- Project cards with: title (huge), category tag, year, one-line description, "VIEW PROJECT →" link
- Bold hover effects: color invert, border thickening, text shift
- Asymmetric grid — some cards span full width, others offset 2-column
- Grayscale image placeholders with harsh crops

### 4. Services / Capabilities
- Poster-style text layout — large category words stacked vertically
- Categories: BRANDING, UI DESIGN, ART DIRECTION, VISUAL SYSTEMS, CREATIVE DEVELOPMENT
- Each with a small descriptor line, separated by harsh horizontal rules
- Index numbers on the left side

### 5. Process / Philosophy
- Large quote-style manifesto typography filling the viewport
- One or two bold statements in oversized type
- Sparse layout with dramatic whitespace
- Acid yellow accent on a key word or punctuation mark

### 6. Contact + Footer
- Big "LET'S WORK" headline
- Email displayed as large clickable monospace text
- Social links as uppercase text labels in a horizontal row
- Footer styled as an industrial label/stamp: copyright, year, location
- Marquee scrolling text strip at the bottom with repeated tagline

## Interactions & Navigation
- Minimal sticky top nav: name left, section links right, all uppercase, no background
- Smooth scroll to section anchors
- Scroll-triggered reveal animations (sharp slide-up, not fade)
- Bold hover states throughout: inversions, underline expansions, border shifts
- Fully responsive — mobile retains brutalist character with stacked layout and preserved typography hierarchy
